新版 Gymnasium 的 `step()` 返回 5 个值：

```python
obs, reward, terminated, truncated, info = env.step(action)
```

- `obs`：执行动作后的新画面；
- `reward`：这一步获得的奖励；
- `terminated`：游戏是否自然结束，比如被敌人打中死亡；
- `truncated`：是否被外部条件截断，比如达到最大步数；
- `info`：调试信息字典。

旧版 Gym 里只有一个 `done`，现在拆成了 `terminated` 和 `truncated`，这样能区分“真的输了”和“只是时间到了”。

|          字段          |       含义       |                   说明                    |
| :--------------------: | :--------------: | :---------------------------------------: |
|        `lives`         |  当前剩余生命数  |   太空侵略者里通常是 3，表示还有几条命    |
| `episode_frame_number` | 当前回合内的帧数 | 从本次 `reset()` 开始算起，已经走了多少帧 |
|     `frame_number`     |   模拟器总帧数   |       从环境创建后累计运行的总帧数        |

### LunarLander（月球着落器）

```python
import gymnasium as gym
import matplotlib.pyplot as plt
from IPython import display
import time

# 设置中文显示
plt.rcParams["font.sans-serif"] = ["SimHei"]
plt.rcParams["axes.unicode_minus"] = False

# 创建环境，这里采用离散动作模式（4个动作）
env = gym.make("LunarLander-v3", render_mode="rgb_array")
obs, info = env.reset()

# 准备画布
fig, ax = plt.subplots(figsize=(6, 6))
img = ax.imshow(env.render())
ax.axis("off")
ax.set_title("月面着陆器 - 自动飞行中")
plt.tight_layout()
display.display(fig)

total_reward = 0
step_count = 0

# 开始自动循环执行，直到回合结束
while True:
    # 随机选择动作（如果想看智能体乱飞的样子就保持这个）
    action = env.action_space.sample()
    
    # 执行动作
    obs, reward, terminated, truncated, info = env.step(action)
    total_reward += reward
    step_count += 1
    
    # 刷新画面
    img.set_data(env.render())
    ax.set_title(f"步数: {step_count} | 累计奖励: {total_reward:.1f} | 生命={info.get('lives', 'N/A')}")
    display.clear_output(wait=True)
    display.display(fig)
    time.sleep(0.02)  # 稍微暂停一下，防止刷新过快看不清
    
    # 判断是否结束
    if terminated or truncated:
        break

# 打印结束总结
print(f"🏁 回合结束！")
print(f"   - 总步数: {step_count}")
print(f"   - 最终累计奖励: {total_reward:.2f}")
print(f"   - 终止原因: {'自然结束(成功/失败)' if terminated else '被截断(超时)'}")

# 释放资源
env.close()
plt.close(fig)
```

`LunarLander-v3` 默认离散动作空间有 **4 个动作**，编号 0~3。

| 动作编号 |             含义              |              实际效果              |
| :------: | :---------------------------: | :--------------------------------: |
|    0     |          do nothing           |        不点火，只受重力下落        |
|    1     | fire left orientation engine  |       点燃左侧引擎，推力向右       |
|    2     |       fire main engine        | 点燃主引擎，向上推，用于减速或爬升 |
|    3     | fire right orientation engine |       点燃右侧引擎，推力向左       |

### CartPole（**推车倒立摆**）

CartPole 默认的规则：

- **每走一步（每一个 step），只要杆子还没倒，就给 +1 的奖励**
- 什么时候回合结束：杆子倾斜超角度、小车跑出边界，回合立刻终止，不再拿奖励
- 这个环境最大上限：最多走 200 步（老版本是 200，新版 gym 有时候 500），到上限回合也结束

所以：**这个环境里，总奖励 = 这个回合一共跑了多少 step** 能跑越久，总分越高。 目标就是：尽量拖久一点，不要倒，让这一局的总步数（总奖励）最大化。

```python
import gymnasium as gym
import matplotlib.pyplot as plt
from IPython import display
import time

plt.rcParams["font.sans-serif"] = ["SimHei"]
plt.rcParams["axes.unicode_minus"] = False

# 创建环境，自行结束
# env = gym.make("CartPole-v1", render_mode="rgb_array")

# 截断环境的最大步数为50步
env = gym.make("CartPole-v1", render_mode="rgb_array", max_episode_steps=50)
obs, info = env.reset()

# 准备画布
fig, ax = plt.subplots(figsize=(6, 4))
img = ax.imshow(env.render())
ax.axis("off")
ax.set_title("CartPole - 自动随机运行中")
plt.tight_layout()
display.display(fig)

total_reward = 0.0
step = 0

# 自动随机运行直到回合结束
while True:
    action = env.action_space.sample()
    obs, reward, terminated, truncated, info = env.step(action)
    total_reward += reward
    step += 1

    img.set_data(env.render())
    ax.set_title(f"步数={step}, 动作={action}, 累计奖励={total_reward:.1f}")
    display.clear_output(wait=True)
    display.display(fig)
    time.sleep(0.03)

    if terminated or truncated:
        break

print(f"回合结束！总步数={step}, 累计奖励={total_reward:.2f}")
print(f"终止原因: {'自然结束' if terminated else '被截断(超时)'}")

env.close()
plt.close(fig)
```

CartPole 只有两个动作：

| 动作 |    含义    |
| :--: | :--------: |
|  0   | 小车向左推 |
|  1   | 小车向右推 |

杆子一旦倾斜角度太大，或者小车跑出边界，回合就会结束。随机动作通常只能撑十几步到几十步。

* obs代表内容

在代码 `obs, info = env.reset()` 或 `obs, reward, terminated, truncated, info = env.step(action)` 中，返回的 `obs`（观察状态）就是一个长度为 4 的浮点数数组 `[a, b, c, d]`。它们分别代表当前环境的物理状态：

第 1 个浮点数：小车位置 (Cart Position)

- 小车在轨道上的水平坐标（中心为原点）。
- *规则*：如果该值小于 -2.4 或大于 2.4，小车冲出轨道，游戏结束（触发 `terminated`）。

第 2 个浮点数：小车速度 (Cart Velocity)

- 小车水平方向移动的速度。

第 3 个浮点数：杆子角度 (Pole Angle)

- 杆子偏离垂直方向的角度（0 代表完全竖直）。
- *规则*：如果该值小于 -0.209 弧度（-12度）或大于 0.209 弧度（12度），杆子倾斜过度，游戏结束（触发 `terminated`）。

第 4 个浮点数：杆子角速度 (Pole Velocity at tip)

- 杆子转动的速度。

* torch中带有下划线的方法

```python
x3 = torch.tensor([[3, 4, 6], [2, 1.0, 5]])
x4 = torch.tensor([[1, 0, 0], [0, 1.0, 0]])

都是就地操作，也就是x3会发生变化
>>> x3.add_(x4) 
tensor([[4., 4., 6.],  [2., 2., 5.]])

```

Any method with _ indicates that it is an in-place operation, which updates the tensor with the resulting value.
